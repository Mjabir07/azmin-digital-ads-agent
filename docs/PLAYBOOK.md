## 1. Strategy
- One Click-to-WhatsApp campaign, UAE only (Dubai, Sharjah, Abu Dhabi, Ajman), AED 75/day for 30 days.
- Goal: 15–30 qualified website enquiries. Add KSA (Riyadh, Jeddah, Dammam) only when cost per
  qualified lead < AED 150.
- Phases: Test (days 1–14, no edits first 72 h) → Optimise (days 15–30) → Scale (month 2, +20% every 3 days, add KSA + retargeting).

## 4. Campaign structure
- Campaign `AZD | UAE | WhatsApp Leads | Website Design` — Objective Engagement → Messaging apps → WhatsApp, goal Maximise conversations, ad-set budgets (ABO).
- Ad set A `UAE | Broad | 25-55` — AED 37.50/day, Advantage+ audience, no interests.
- Ad set B `UAE | Interests | SME owners` — AED 37.50/day, interests: small business owners, entrepreneurship, startups, online advertising.
- Month 2: Ad set C KSA (AED 40/day, Arabic-first); Ad set D retargeting (engagers 60 days, AED 15/day).
- Naming: `Brand | Country | Audience | Offer`.

## 6. WhatsApp sales script
Pre-filled: "Hi! I'm interested in a website for my business."
1. Greet: "Hi 👋 Thanks for contacting AZMIN DIGITAL! I'm Jabir. To give you an accurate quote, may I ask 3 quick questions?"
2. Qualify, one at a time: (a) business + current website? (b) main goal — enquiries, online sales, or image? (c) launch timing + budget range?
3. Proof: 2–3 portfolio links from the same industry + 1 testimonial.
4. Recommend ONE package with price and timeline.
5. Offer a 10-minute call.
6. Close: PDF quote, 50% advance.
Follow-ups: Day 1, Day 3 (new project), Day 7 ("keep your slot or close the file?").
Objections: too expensive → Starter; "I'll think" → ask the one concern; Fiverr → local team, Arabic + English, after-launch support.
